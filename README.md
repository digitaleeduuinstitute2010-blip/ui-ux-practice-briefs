# Web Development Roadmap for Beginners

A step-by-step path from zero to your first job-ready portfolio.
Maintained by the trainers and team at [99EEDU](https://99eedu.com), Kolkata.

## Who is this for?

Students after 12th, college students, freshers and career switchers
who want to start web development with no prior experience.

## Roadmap

### Stage 1: Foundations
- [ ] How the web works (browsers, servers, URLs)
- [ ] HTML: structure, forms, semantic tags
- [ ] CSS: box model, Flexbox, Grid, responsive design
- [ ] Git and GitHub basics

### Stage 2: JavaScript
- [ ] Variables, functions, arrays, objects
- [ ] DOM manipulation and events
- [ ] Fetch API and working with JSON
- [ ] ES6+ features

### Stage 3: Frameworks and tools
- [ ] React: components, props, state, hooks
- [ ] WordPress: themes, plugins, WooCommerce
- [ ] Browser DevTools and debugging

### Stage 4: Job readiness
- [ ] Build 3 to 5 portfolio projects
- [ ] Deploy projects (GitHub Pages, Netlify or Vercel)
- [ ] Write a clear README for every project
- [ ] Prepare a resume and LinkedIn profile

## Practice projects

| Level | Project | Skills |
|---|---|---|
| Beginner | Personal portfolio page | HTML, CSS |
| Beginner | Responsive landing page | Flexbox, media queries |
| Intermediate | To-do list app | JavaScript, DOM, local storage |
| Intermediate | Weather app using a public API | Fetch, JSON |
| Advanced | Product catalogue in React | Components, state, routing |
| Advanced | Small WooCommerce store | WordPress, WooCommerce |

## Tips

1. Code a little every day instead of cramming on weekends.
2. Build projects instead of only watching tutorials.
3. Commit your work regularly so employers can see your progress.
4. Read other people's code and ask questions.
